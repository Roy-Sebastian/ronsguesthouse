Setelah pengguna berhasil login, sistem membuat session token yang disimpan dalam HTTP-only cookie dengan masa berlaku 24 jam. Setiap request ke endpoint terproteksi divalidasi melalui auth.api.getSession(); jika session tidak valid maka server menolak dengan status 401, dan jika akun dinonaktifkan admin maka server menolak dengan status 403 meskipun session masih aktif. Potongan kode pembuatan session token dapat dilihat pada Kode 4.4 berikut.
