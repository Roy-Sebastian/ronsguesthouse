Sistem menangani pengunggahan file gambar menggunakan library Multer dengan validasi tipe file berdasarkan MIME type di sisi server, hanya mengizinkan format JPEG, PNG, WebP, dan GIF. Setiap file disimpan dengan nama unik yang dibentuk dari timestamp dan angka acak untuk mencegah tabrakan nama, dengan batas ukuran maksimal 5 MB. Potongan kode unggah file gambar dapat dilihat pada Kode 4.15 berikut.
